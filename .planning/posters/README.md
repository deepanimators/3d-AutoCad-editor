## How to use these files

### For AI image generation (Midjourney, DALL-E, Stable Diffusion)
Copy the prompt from the **"AI Image Generation Prompt"** section of each file.
Paste directly into your tool. Adjust `--ar` flag for your target format.

### For human designers (Canva, Figma, Adobe)
Use the **"Design Brief"** table + **"Layout Sketch"** as your creative brief.
Copy the **Headline Copy** section for exact wording.

### For ad platforms (Google, Meta, LinkedIn)
Use the short-form copy variants and the **"Alternate headline options"** sections.
Each file includes platform-specific character counts where relevant.

### For email campaigns
Use the **"Email subject lines"** section at the bottom of each file.
