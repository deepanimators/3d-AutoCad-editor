## Design Brief

| Element | Spec |
|---|---|
| Audience | Developers + AI-curious architects |
| Visual metaphor | Chat → 3D output, terminal → building |
| Key technical element | Show the `npx @aruct/mcp` command prominently |
| Tone | Smart, slightly nerdy, confident — not corporate |
| Color | Darker, more terminal-like: near-black background, monospace fonts, green or cyan accents |
| CTA | "Available on Pro, $29/month" — price visible but not the focus |
