## Design Brief

| Element | Spec |
|---|---|
| Headline positioning | Collaboration first — "together" is the core value prop |
| Visual | Multiple screens / users on same scene, or multi-cursor UI overlay |
| Trust signals | "IFC export" and "SSO/SAML" — these signal enterprise readiness |
| Price framing | Show the comparison: BIM licenses vs Aruct Team cost |
| CTA | "Bring your team" — action-oriented, group framing |
| Tone | More corporate than Pro poster — less playful, more reliable |
