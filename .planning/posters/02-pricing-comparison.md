**Placement:** Pricing page hero, social media, landing page section, email header

## Design Brief

| Element | Spec |
|---|---|
| Background | `#0f172a` dark navy |
| Card style | Three vertical cards, equal width, subtle border `rgba(255,255,255,0.08)` |
| Pro card | Slightly elevated (shadow / glow), blue border `#3b82f6`, "Most popular" chip |
| Type hierarchy | Tier name → Price (large) → Feature list (small mono) → CTA button |
| CTA buttons | Free: outlined · Pro: filled blue · Team: outlined white |
| Footer | "14-day free trial · No credit card required" centered, muted text |
