## Design Brief

| Element | Spec |
|---|---|
| Hero message | Price upfront: "$29/mo" should be the biggest number on the poster |
| Visual metaphor | "Before/after" — basic vs. advanced output, or locked→unlocked |
| Trial emphasis | "14-day free trial" must appear prominently — removes purchase anxiety |
| Feature highlights | 5–6 max, with checkmarks, scannable |
| CTA color | Filled blue button — strongest visual weight on the page |
