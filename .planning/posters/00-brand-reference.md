## What Is Aruct

Aruct is a **web-based 3D architectural design editor** — no install, runs in the browser.
It lets architects, interior designers, and construction teams design buildings in 2D and 3D,
run analyses, generate exports for BIM workflows, and collaborate in real time.

Core differentiator: **the only browser-native architectural editor with MCP server support**,
meaning AI tools (Claude, Cursor, etc.) can read and write scenes directly via the Model Context Protocol.

## Core Features (from codebase)

- **2D + 3D dual view** — design in floorplan or 3D simultaneously
- **Walls, doors, windows, slabs, roofs, stairs** — full building element library (free)
- **Sun & Shadow Study** — solar path simulation by GPS location + time of day (Pro)
- **Bill of Materials (BOM)** — auto-count elements, export CSV/PDF (Pro)
- **IFC / BIM Export** — IFC 2x3 + IFC 4, compatible with Revit, ArchiCAD, BIMx (Team)
- **Real-time collaboration** — live cursors, presence, multi-user editing (Team)
- **Model Catalog** — Poly Haven + Poly Pizza CC0 3D model libraries built in (Free)
- **AI Model Generator** — text-to-3D via Tripo3D, auto-saves to catalog (Pro)
- **MCP Server** — Claude/Cursor can manipulate scenes via code (Pro)
- **Scene sharing** — public/private links, embeddable viewer

## Brand Voice

- **Confident, minimal, technical but not intimidating**
- "Design without limits" / "Architecture, rethought" — directional tone
- Not a SaaS startup feel — more like a precision tool for professionals
- Color direction: dark/deep backgrounds, clean white type, brand blue accent (`#2563EB` range)
- Avoid: clipart, stock people photos, cartoonish illustration
