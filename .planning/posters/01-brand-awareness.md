**Goal:** First impression. Make people ask "what is this?"  
**Placement:** Social media (Instagram, LinkedIn), conference booth, website hero banner  
**Format:** 1:1 (social), 16:9 (banner), A2 print

---

## Design Brief (for Canva / Figma / human designer)

| Element | Spec |
|---|---|
| Background | Deep navy `#0f172a` or near-black `#030712` |
| Primary type | White, large, left-aligned, condensed sans (Inter, DM Sans, or Neue Haas) |
| Accent color | Electric blue `#3b82f6` — glow effects, highlights |
| Visual centerpiece | 3D wireframe or rendered building in isometric view |
| Secondary type | Gray `#94a3b8` for sub-headline and URL |
| Negative space | Heavy — 50%+ of canvas should breathe |
| Logo | Top-left or bottom-left, white, small |
| CTA | Bottom strip, subtle border, white text |
