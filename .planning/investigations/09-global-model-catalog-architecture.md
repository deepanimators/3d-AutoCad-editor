# Investigation 09 — Global Model Catalog Architecture

**Date:** 2026-07-26  
**Status:** Design / Planning  
**Trigger:** User requirement: free-source 3D models cached in S3, globally available to all users, with auto-expiring "New" tag (>10 days old = remove tag)

---

## Requirements

1. **Global shared catalog** — when any user discovers/imports a free model, it is stored once in S3 and available to all users
2. **"New" tag** — models added within the last 10 days show a "New" badge in the UI
3. **Auto-expiry** — after 10 days, the "New" tag is automatically removed (no manual action)
4. **Sources** — Tripo3D gallery (CC BY 4.0), Sketchfab free tier, Poly Pizza, Smithsonian 3D, and other free-license GLB/GLTF sources
5. **Search** — users can search the catalog by keyword, category, source
6. **Import** — one-click import directly into the current scene

---

## Data Model

### `global_models` table (Neon Postgres)

```sql
CREATE TABLE global_models (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug         TEXT UNIQUE NOT NULL,           -- url-safe identifier
  name         TEXT NOT NULL,
  description  TEXT,
  source       TEXT NOT NULL,                  -- 'tripo3d' | 'sketchfab' | 'polypizza' | 'smithsonian'
  source_id    TEXT,                           -- original ID on source platform
  source_url   TEXT,                           -- original page URL (for attribution)
  license      TEXT NOT NULL,                  -- 'CC BY 4.0' | 'CC0' | 'Sketchfab Standard' etc.
  attribution  TEXT,                           -- attribution string required by license
  s3_key       TEXT NOT NULL,                  -- S3 object key for GLB file
  s3_thumbnail TEXT,                           -- S3 key for thumbnail image
  file_size_bytes BIGINT,
  poly_count   INTEGER,
  tags         TEXT[],
  category     TEXT,
  added_at     TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  added_by     UUID REFERENCES users(id),      -- NULL if ingested by system
  CONSTRAINT source_unique UNIQUE (source, source_id)
);

CREATE INDEX idx_global_models_added_at ON global_models(added_at DESC);
CREATE INDEX idx_global_models_category ON global_models(category);
CREATE INDEX idx_global_models_tags ON global_models USING gin(tags);
```

### "New" Tag Logic

No dedicated boolean column needed. Computed at query time:

```sql
-- is_new = added within last 10 days
SELECT *, (added_at > NOW() - INTERVAL '10 days') AS is_new
FROM global_models
ORDER BY added_at DESC;
```

**Why computed, not stored:** A stored `is_new` flag requires a cron job to flip it. A computed column is always correct without any background job — the DB does the math.

## S3 Storage Layout

```
s3://aruct-assets/
  global-models/
    {source}/
      {slug}/
        model.glb          # primary GLB file
        thumbnail.webp     # 512x512 preview image
        metadata.json      # source metadata snapshot
```

**Example:**
```
s3://aruct-assets/global-models/tripo3d/concrete-chair-v1/model.glb
s3://aruct-assets/global-models/sketchfab/barcelona-chair-1234/model.glb
```

### S3 Configuration
- **Bucket:** `aruct-assets` (existing or new)
- **Region:** `us-east-1` (or same as Neon Postgres region)
- **Public read:** Yes for `global-models/` prefix (models are free-licensed)
- **Lifecycle policy:** None (models are permanent catalog entries)

## Ingestion Pipeline

### Path 1: User-triggered import

1. User searches external source (Sketchfab, Tripo gallery, etc.)
2. User clicks "Import to Aruct"
3. API route: `POST /api/catalog/import`
   ```json
   { "source": "sketchfab", "source_id": "abc123", "download_url": "..." }
   ```
4. Server checks `global_models` table: already exists? Return existing record.
5. If new: download GLB → upload to S3 → insert `global_models` row → return model record
6. Model immediately available to all users with `is_new = true` for 10 days

### Path 2: Bulk ingestion (background job)

Cron or one-time script that scrapes free model sources and bulk-inserts into the catalog.

## API Routes

### `GET /api/catalog`

Search the global catalog.

```
GET /api/catalog?q=chair&category=furniture&source=tripo3d&page=1&limit=24
```

Response:
```json
{
  "models": [
    {
      "id": "uuid",
      "name": "Concrete Chair",
      "slug": "concrete-chair-v1",
      "source": "tripo3d",
      "license": "CC BY 4.0",
      "attribution": "Generated by Tripo3D, CC BY 4.0",
      "glbUrl": "https://assets.aruct.com/global-models/tripo3d/concrete-chair-v1/model.glb",
      "thumbnailUrl": "https://assets.aruct.com/global-models/tripo3d/concrete-chair-v1/thumbnail.webp",
      "isNew": true,
      "addedAt": "2026-07-26T10:00:00Z",
      "tags": ["furniture", "concrete", "modern"],
      "category": "furniture"
    }
  ],
  "total": 142,
  "page": 1
}
```

### `POST /api/catalog/import`

Import a model from an external source into the global catalog.

```json
{
  "source": "sketchfab",
  "sourceId": "abc123",
  "downloadUrl": "https://...",
  "name": "Barcelona Chair",
  "license": "CC BY 4.0",
  "attribution": "Barcelona Chair by User123 on Sketchfab, CC BY 4.0"
}
```

**Idempotent** — calling twice with same `(source, sourceId)` returns existing record.

### `GET /api/catalog/[id]`

Get single model details + signed S3 URL if needed.

## Deduplication Strategy

Before downloading and uploading to S3, always check:

```sql
SELECT id, s3_key FROM global_models 
WHERE source = $1 AND source_id = $2
LIMIT 1;
```

If found → return existing record immediately (no re-download, no duplicate S3 object).

Additionally, for Tripo3D: identical GLB files may come from different source URLs. Consider hashing the GLB file and indexing on hash for content-addressed deduplication.

## Open Questions

1. **Tripo3D gallery scraping** — No public API exists. Need to reverse-engineer the gallery endpoints or use Playwright for scraping. Legal review needed for ToS compliance.
2. **S3 bucket naming** — Use existing `aruct-assets` bucket or create dedicated `aruct-model-catalog`?
3. **CDN** — Should S3 URLs be served via CloudFront for performance? (Especially for global users.)
4. **GLB validation** — Should we validate/sanitize GLB files before storing? (Security: malicious 3D files can embed scripts in some formats.)
5. **Storage costs** — GLB files are typically 1–20MB each. 10,000 models ≈ 100GB. At $0.023/GB/mo (S3 standard) = ~$2.30/mo for storage alone.
